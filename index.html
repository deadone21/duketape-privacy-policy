DUKETAPE Privacy Policy

Last updated: September 8, 2026

DUKETAPE is a personal automation and content management project that uses APIs from third-party platforms such as Pinterest and Amazon Associates/Creators API where applicable.

1. Information We Access

Depending on the enabled features, DUKETAPE may access information from connected platforms such as:

  • Pinterest account and profile information necessary for API access.
  • Pinterest Pins, boards, analytics and performance information belonging to the connected account.
  • Product information obtained through Amazon affiliate APIs or other authorized sources.

2. How We Use Information

The information is used only to operate, analyze and improve the DUKETAPE automation workflow, including:

  • Creating and scheduling Pinterest Pins.
  • Analyzing Pinterest content performance.
  • Researching content and fashion trends.
  • Generating titles, descriptions, tags and hashtags.
  • Managing affiliate product information and links.

3. Data Storage

DUKETAPE is designed primarily as a local automation system. Information processed by the application may be stored locally on the user's device or server running the application.

API credentials and access tokens should be stored securely and should not be included directly in publicly accessible source code.

4. Data Sharing

DUKETAPE does not sell personal information to third parties. Information is only transmitted to third-party services when necessary to use their APIs or provide a requested feature.

5. Third-Party Services

DUKETAPE may interact with third-party services including Pinterest, Amazon and other APIs selected by the application owner. Those services have their own privacy policies and terms.

6. Data Deletion

Locally stored application data can be deleted by removing the corresponding local application data, database files or credentials. For data maintained by third-party platforms, deletion is handled according to the policies and controls of those platforms.

7. Security

Reasonable measures are used to protect API credentials and locally stored application data. Credentials should be stored in environment variables or other secure secret-storage mechanisms and should not be committed to public repositories.

8. Changes to This Policy

This privacy policy may be updated when the DUKETAPE project or its API integrations change. The latest version will always be published on this page.

9. Contact

For privacy-related questions regarding DUKETAPE, contact the project owner through the official DUKETAPE project channels.
